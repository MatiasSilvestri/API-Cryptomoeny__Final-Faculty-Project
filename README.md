CryptoInfo es una Plataforma Web Desarrollada con el propósito de proporcionar información actualizada sobre el precio de criptomonedas más relevantes del mercado, presentando sus valores expresados en moneda argentina. El sistema busca facilitar el acceso a datos financieros relacionados con activos digitales, permitiendo a los usuarios consultar información de manera rápida, organizada y confiable. La aplicación se estructura sobre una base de datos que almacena información detallada de cada criptomoneda, incluyendo su nombre, precio actual, variación porcentual registrada durante las últimas 24 horas y capitalización bursátil. Estos datos son consultados por los usuarios a través de una interfaz web intuitiva diseñada para optimizar la experiencia de navegación.
	Asimismo, el sistema incorpora un módulo de gestión de usuarios que permite el registro e inicio de sesión mediante un formulario seguro. Durante el proceso de registro se recopilan datos personales básicos, tales como Nombre, Apellido, Correo Electrónico y Contraseña, garantizando la identificación de cada usuario dentro de la plataforma.
